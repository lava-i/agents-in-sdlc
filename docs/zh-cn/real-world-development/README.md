通过真实场景、完整应用程序和共享待办事项，在整个软件开发生命周期中探索 GitHub Copilot。你将通过迭代方式规划更改、编写代码、测试行为、审查拉取请求，并使用代理管理工作。

## 场景

你是 Tailspin Toys 的新开发人员。这是一家虚构的公司，为带有开发主题的桌游提供众筹服务。团队的待办事项已登记为 GitHub 议题，你可以直接选择任务开始处理。其中既有筛选和分页等功能，也有无障碍和编码规范等质量改进。

## 选择工作环境

无论你在哪里工作，都可以使用 GitHub Copilot。选择最适合你的构建方式的环境。每个研讨会都有自己的设置步骤，并使用相同的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理式助手。体验 Plan 和 Autopilot 模式、指令、技能、自定义代理、Playwright MCP、Agent Merge 以及实用的斜杠命令。

### [GitHub Copilot app][app]

运行并行代理会话、切换会话模式、在 Canvas 中协作，并在桌面应用中管理 GitHub 议题和拉取请求。

### [GitHub Copilot 云智能体][cloud]

将 GitHub 议题分配给异步代理、引导其工作、监控进度，并审查代理创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 代理模式、MCP 服务器和自定义代理。
